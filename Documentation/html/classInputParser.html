Detailed Description

Parser para ficheiros de input do projeto de register allocation.

Responsavel por:

  • Parse ranges.txt: variaveis com live ranges
  • Parse registers.txt: numero de registos + algoritmo

std::vector<Web> InputParser::buildWebs ( ) const

Construir webs a partir dos live ranges parseados.

Estratégia:

  1. Para cada variável com múltiplos live ranges
  2. Merge ranges que se sobrepõem (greedy approach)
  3. Retornar lista de webs únicos
Complexidade Temporal:
O(v * r^2) onde v = variaveis e r = ranges por variavel.

◆ parseRanges()

bool InputParser::parseRanges ( const std::string &  filename)
inline

Parse ficheiro ranges.txt.

Formato esperado:

# comentário (ignorado)
sum: 7+,8,9,10-
i: 1+,2,3,4,5,6-
i: 9+,10,11,12-

Onde:

  • "+" = definição (assignment LHS)
  • "-" = último uso (RHS)
  • Múltiplas linhas da mesma variável = múltiplos live ranges
Parameters
filenameCaminho ficheiro ranges.txt
Returns
true se parse bem-sucedido, false caso contrario
Complexidade Temporal:
O(L + T) onde L = linhas do ficheiro e T = tokens totais.

◆ parseRegisters()

bool InputParser::parseRegisters ( const std::string &  filename)
inline

Parse ficheiro registers.txt.

Formato esperado:

# comentário
registers: 3
algorithm: basic

Ou com parâmetro:

registers: 2
algorithm: spilling, 2

Algoritmos suportados:

  • basic: greedy coloring simples
  • spilling K: permite spill até K webs
  • splitting K: permite split até K webs
  • free: algoritmo livre
Parameters
filenameCaminho ficheiro registers.txt
Returns
true se parse bem-sucedido, false caso contrario
Complexidade Temporal:
O(L) onde L = linhas do ficheiro.
